# Machine Learning Exercises

Projeto desenvolvido para prática de conceitos de Python aplicados à análise de dados e Machine Learning.

## Objetivo

Este repositório contém exercícios e implementações de funções utilizadas no aprendizado de programação, manipulação de dados e preparação para projetos de Machine Learning.

## Estrutura do projeto

- `funcoes.py`
  - Contém funções reutilizáveis desenvolvidas durante os exercícios.

- `desenvolvimento.py`
  - Arquivo principal utilizado para testar e executar as funções criadas.

## Tecnologias utilizadas

- Python 3.10
- Pandas
- NumPy

## Conceitos praticados

- Criação de funções
- Manipulação de dados
- Estruturas condicionais
- Laços de repetição
- Organização de código
